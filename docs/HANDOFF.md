## 현재 상태
- **0단계 완료**: Vite + React + TypeScript 프로젝트 세팅, 폴더 정리, git 저장소 생성(아직 커밋 없음)
- 탭 4개(식단·레시피·장보기·찜) 뼈대만 있고, 화면 내용은 "준비 중"

## 실행 방법
```
npm install     # 처음 한 번
npm run dev     # 개발 서버 → 터미널에 나온 주소(예: http://localhost:5173)로 접속
npm run build   # 타입 검사 + 배포용 파일(dist/) 만들기
```
- 5173 포트가 이미 사용 중이면 `npm run dev -- --port 5180`
- **빌드 주의**: Node 24의 `fs.rmSync`가 한글 경로(식단앱)에서 프로그램째 죽어요 (종료 코드 -1073740791). 그래서 `vite.config.ts`에서 `emptyOutDir: false`로 끄고, `npm run build`가 `fs.promises.rm`으로 dist를 먼저 비워요. 빌드 결과를 확인할 땐 출력 끝만 보지 말고 종료 코드를 확인할 것
