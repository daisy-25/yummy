# 저녁 식단 앱 기능 정의서

> 마지막 수정: 2026-10-21
> 이 문서가 기준이에요. 기능을 더하거나 바꾸면 여기부터 고치고, 코드는 그다음에 고쳐요.

## 1. 무엇을 위한 앱인가

**메뉴를 추천받고 → 쉬운 영상 레시피로 따라 하고 → 맛있었던 건 우리 방식으로 기록하고 → 손에 익으면 레시피 없이 장보기만 도와주는 앱**

| 항목 | 내용 |
|---|---|
| 쓰는 사람 | 2인 가구. 한 명은 고기를 아주 좋아함 |
| 끼니 | 하루 저녁 한 끼. 넉넉히 만든 메뉴는 다음 날 회사 도시락 |
| 요리 실력 | 초보 (라면, 간단한 무침 정도) |
| 조리 도구 | 가스레인지(인덕션), 냄비, 프라이팬, 전자레인지 |
| 못 먹는 재료 | 가지, 조개류, 홍어, 미역줄기 |
| 쓰는 곳 | 휴대폰 홈 화면에 추가해서 앱처럼 (GitHub Pages 배포) |

### 지키는 원칙
1. **귀찮으면 안 쓴다.** 새로 적어야 하는 것을 줄이는 기능이 화려한 기능보다 먼저다.
2. **메뉴와 레시피는 따로다.** 레시피가 없어도 메뉴만 있으면 장보기가 된다.
3. **짐작한 숫자는 넣지 않는다.** 가격처럼 정확하지 않고 매번 고쳐야 하는 데이터는 뺀다.
4. **우리 데이터는 우리 손에.** 폰에 저장되는 기록은 언제든 파일로 내보낼 수 있어야 한다.

## 2. 화면 구성 (하단 탭 4개)

| 탭 | 한 줄 설명 | 주요 기능 |
|---|---|---|
| **식단** | 이번 주 저녁 뭐 먹지 | 요일 선택, 오늘 메뉴, 주간 목록, 추천받기 |
| **레시피** | 어떻게 만들지 | [저녁 메뉴 · 냉동 밀프랩] 두 갈래. 대표 레시피, 다른 영상 4개, 메모, 하트 |

## 3. 기능 상세

표시: `1차` = 첫 버전에 넣음 · `2차` = 쓰다가 필요하면 · `제외` = 안 만듦

### 3-1. 식단 탭

| 기능 | 단계 | 설명 |
|---|---|---|
| 요일 줄 | 1차 | 월~일 날짜. 오늘 표시, 선택한 날 강조. 도시락이 생기는 날은 작은 점 |
| 오늘 메뉴 | 1차 | 선택한 날의 메뉴 이름(크게), 곁들임, 조리시간, 난이도, 도시락 여부. 버튼: 레시피 보기, 재료 |
| 주간 목록 | 1차 | 7일 메뉴 목록. 누르면 해당 레시피로 이동 |
| 이번 주 요약 | 1차 | 고기 몇 번 · 국물 몇 번 · 도시락 몇 번 |
| **추천받기** | 1차 | 빈 주를 규칙에 따라 7일 자동 채우기 (규칙은 4장) |
| 다시 뽑기 | 1차 | 마음에 안 드는 날만 다른 메뉴로 바꾸기 |
| 고정 | 1차 | 마음에 드는 날은 고정. 다시 뽑아도 안 바뀜 |
| 직접 고르기 | 1차 | 메뉴 도감에서 골라 넣기 |
| 글 메모 | 1차 | 메뉴 대신 "외식", "건너뜀" 같은 글. 장보기에 영향 없음 |
| 도시락 연결 | 1차 | "넉넉히 만들기"를 켜면 다음 날에 "점심 도시락"으로 표시 |
| 해먹었어요 | 1차 | 그날 메뉴를 실제로 해먹었으면 체크 → 기록에 쌓임 (추천 규칙에 쓰임) |
| 주 고르기 | 1차 | 다음 주 미리 짜기 + 지난 주들을 거슬러 보기 |
| 지난주 복사 | 2차 | 마음에 든 주를 그대로 다시 쓰기 |

### 3-2. 레시피 탭

| 기능 | 단계 | 설명 |
|---|---|---|
| 메뉴 고르기 | 1차 | 이번 주 메뉴가 위에 나오고, 전체 도감에서 검색 |
| 한 줄 요약 | 1차 | 기준 분량 · 시간 · 난이도 · 도시락 가능 |
| **대표 레시피** | 1차 | 영상 1개를 글로 완전히 정리. 필요한 도구 → 재료 체크리스트 → 단계 |
| 단계에 분량 | 1차 | "양파를 썬다"가 아니라 "양파 1/2개를 채 썬다" |
| 준비/조리 구분 | 1차 | 단계를 [준비](썰기·계량)와 [조리](불 위)로 나눔 |
| 이 부분 보기 | 1차 | 단계 옆 버튼 → 그 장면부터 유튜브 재생 (쇼츠는 제외) |
| 대표 썸네일 | 1차 | 대표 영상만 작은 썸네일. 나머지는 글자만 |
| **다른 영상 4개** | 1차 | 채널 · 조회수 · 길이 한 줄씩. 누르면 유튜브로 |
| 확인 필요 표시 | 1차 | 자동 자막에서 뽑아 불확실한 분량은 "영상에서 확인" 표시 |
| 계량 안내 | 1차 | 1큰술 = 밥숟가락 수북이 1번 같은 공통 안내 팝업 |
| **하트** | 1차 | "또 해먹을래". 찜 탭에 모이고 추천 점수가 올라감 |
| **내 메모** | 1차 | 내 입맛에 맞게 바꾼 점. 날짜 자동, 여러 개 쌓임. 레시피 맨 위에 표시 |
| **안 보고 해요** | 1차 | 켜면 레시피가 접히고 재료 · 황금 비율 · 내 메모만 남음 (5장) |
| 화면 꺼짐 방지 | 2차 | "요리 시작"을 누르면 화면이 안 꺼짐 (배포 후 https에서만 동작) |
| 요리 모드 | 2차 | 한 화면에 한 단계씩 크게, 타이머 |
| 요리 용어 설명 | 2차 | "한소끔", "자작하게"를 누르면 설명 |

**냉동 밀프랩** (레시피 탭 안의 두 번째 갈래: 레시피 탭 → 밀프랩 → 요리 → 레시피)

| 기능 | 단계 | 설명 |
|---|---|---|
| 밀프랩 목록 | 1차 | 얼려두기 좋은 요리. ① 밀프랩 전용(주먹밥, 브리또, 떡갈비) ② 저녁 메뉴 중 얼려도 되는 것(카레, 제육 등) |
| 얼리는 법 한 줄 | 1차 | "양념해서"(날고기를 양념에 재워 얼림) / "완성해서"(다 만들어 소분), 몇 팩, 먹는 법. 공통 안내: 한 달 안에 먹기 |
| 장보기에 담기 | 1차 | "+ 장보기에 담기 → ✓ 담았어요". 재료가 장보기에 들어가고, 식단 탭에 "이번 주 밀프랩" 한 줄 |
| 한 번에 여러 개 영상 | 1차 | 냉동실 채우는 하루를 보여주는 영상 몇 개 (`data/prepVideos.ts`) |
| 냉동실에 남은 팩 수 | 2차 | 꺼내 먹을 때 하나씩 줄이기. 귀찮으면 안 씀 |

### 3-3. 장보기 탭

| 기능 | 단계 | 설명 |
|---|---|---|
| **자동 생성** | 1차 | 이번 주 메뉴의 재료를 모아서 자동으로 만듦. 직접 쓰지 않음 |
| 이번 주 / 다음 주 | 1차 | 주말엔 다음 주 장보기를 먼저 보여줌 |
| 재료 합치기 | 1차 | 같은 재료는 한 줄로. 아래에 "(제육볶음, 김치찌개)"처럼 쓰는 메뉴 표시 |
| 코너별 묶음 | 1차 | 정육 → 채소 → 두부·계란 → 가공·기타 → 양념·소스 순서 |
| 체크 | 1차 | 누르면 줄 긋고 그 코너 맨 아래로. 메뉴를 바꿔도 체크가 남음 |
| **집에 늘 있는 재료** | 1차 | 쌀, 김치, 간장 등은 회색으로 접혀 있음. 떨어졌으면 눌러서 목록으로 꺼냄 |
| 직접 추가 | 1차 | 메뉴와 상관없이 살 것 (휴지, 우유 등) |
| 밀프랩 재료 | 1차 | "이번 주 만들기"를 누른 밀프랩의 재료도 같이 모음 |
| 쿠팡 · 컬리 검색 링크 | 2차 | 재료 이름으로 검색되는 링크 |
| 목록 공유 | 2차 | 글로 복사해서 카톡으로 보내기. 나중엔 두 사람 실시간 공유 |
| 가격 · 남은 금액 | **제외** | 추정치라 정확하지 않고 매주 고쳐야 함. 필요해지면 "이번 주 쓴 돈" 한 칸만 추가 |

| 칼로리 · 영양 그래프, 알림 | 그만두게 만드는 이유로 꼽힘 |

## 4. 추천 규칙

앱 안의 간단한 규칙으로 뽑아요. AI가 아니라서 비용이 들지 않고 인터넷 없이도 돼요.

### 후보에서 빼는 것
- 못 먹는 재료(가지, 조개류, 홍어, 미역줄기)가 들어간 메뉴 → 도감에 아예 안 넣음
- 최근 14일 안에 해먹은 메뉴
- 밀프랩 전용 메뉴 (`prepOnly`)

### 꼭 지키는 것
- 매일 **단백질 1 + 채소 1 이상**. 메인에 채소가 적으면 곁들임(무침, 쌈, 국)을 붙임
- **주재료 돌리기**: 돼지 2~3번, 닭 1~2번, 소 또는 생선 1번, 두부·계란 1번
- **같은 조리법 이틀 연속 금지** (찌개 다음 날엔 국물 아닌 것)
- **가끔 특식(양식)**은 주 1번 이하
- 일요일 기본값은 "냉장고 털이"

### 점수를 더 주는 것
| 조건 | 이유 |
|---|---|
| 이번 주 다른 메뉴와 재료가 겹침 | 양배추 반 통, 대파 반 단을 다 쓰게 |
| 하트를 누른 레시피가 있는 메뉴 | 좋아한 메뉴가 더 자주 나오게 |
| 도시락 가능 메뉴 | 주 3번 정도 도시락이 생기게 |
| 오래 안 해먹은 메뉴 | 다양하게 |

### 동작
1. **추천받기** → 고정한 날을 빼고 규칙대로 채움
2. **다시 뽑기**(하루) → 그날만 규칙을 지키는 다른 후보로 바꿈
3. 후보가 모자라면 규칙을 하나씩 느슨하게 풀어서 채움 (점수 → 주재료 돌리기 순)

## 5. "안 보고 해요"

메뉴에 "안 보고 해요"를 켜면 레시피 화면이 이렇게 바뀌어요.

```
닭볶음탕                          [안 보고 해요 ✓]
────────────────────────────
필요한 재료   닭 1마리 · 감자 2개 · 양파 1개 · 대파 1대
황금 비율     간장 4 : 고춧가루 3 : 설탕 2 : 다진마늘 1
내 메모       고춧가루 1큰술 줄이기
────────────────────────────
[ 전체 레시피 펼치기 ]
```

- **황금 비율**은 레시피를 정리할 때 함께 뽑아서 메뉴에 저장
- 장보기는 원래대로 동작 (원칙 2)

## 6. 레시피 모으는 법

### 영상 고르기
1. 유튜브에서 "메뉴명 레시피" 검색, 조회수 순 정렬
2. 빼는 것: 먹방 · 리뷰 · 15분 넘는 영상
3. **쇼츠 포함**. 단, 설명란에 레시피가 적힌 쇼츠를 먼저
   - 조회수 순 검색에는 쇼츠가 잘 안 잡혀요 → "관련성 순"으로 한 번 더 찾아서 조회수로 다시 정렬
4. 상위 **5개** 저장

### 대표 레시피 고르기 (5개 중 1개)
- 재료가 적고, 단계가 짧고, 설명란에 분량이 적힌 영상
- 못 먹는 재료가 숨어 있지 않은지 확인 (예: 찌개 육수의 바지락)

### 글로 옮기기
- 우선순위: **설명란 → 사람이 단 자막 → 자동 자막**
- 자동 자막에서 뽑은 분량은 "영상에서 확인" 표시
- 쇼츠는 화면 위 글씨로 분량을 보여주는 경우가 많아 읽지 못할 수 있음 → 표시로 알림
- 분량은 "2인 저녁 + 도시락" 기준으로 맞춤

### 레시피 추가 작업 (`/레시피추가`)
폰에서 좋은 영상을 보면 링크를 모아뒀다가, Claude에게 붙여 넣으면:
1. 영상 정보 · 설명란 · 자막 읽기
2. 재료 사전에 없는 재료 추가
3. 레시피 파일 만들기, 메뉴 도감에 연결
4. 형식 검사(타입 검사) 통과 확인

→ 반복 작업이 되면 명령어로 만들어 둠 (3차 개발 단계)

## 7. 데이터 구조

### 어디에 저장하나

| 구분 | 저장 위치 | 누가 바꾸나 | 내용 |
|---|---|---|---|
| **앱 데이터** | 코드 폴더 (`src/data/`) | Claude가 파일로 | 재료 사전, 메뉴 도감, 레시피 |
| **내 기록** | 폰 브라우저 저장소 → 2차에 공유 저장소 | 앱을 쓰면서 | 주간 식단, 체크, 하트, 메모, 해먹은 날 |

> **바뀐 점**: 처음엔 주간 식단을 `weeks/2026-W43` 같은 파일로 두려고 했지만, 추천받기와 다시 뽑기를 **폰에서** 하니까 결과도 폰에 저장되어야 해요. 그래서 주간 식단은 "내 기록"으로 옮겼어요. 지난 식단은 폰에 쌓이고, 내보내기로 백업해요.
> 공유 저장 전까지는 식단을 짠 폰에서만 보여요.

> **데이터 파일은 `.json`이 아니라 `.ts`로 둬요.** JSON은 형식 검사가 느슨해서 `oinon` 같은 오타를 못 잡아요. `.ts`로 두면 재료·메뉴 이름표 오타까지 저장하는 순간 빨간 줄로 잡혀요. 이름표(id)는 칸이 아니라 목록의 **키**예요.

### 7-1. 재료 사전 `data/ingredients.ts`

| 칸 | 뜻 | 예시 |
|---|---|---|
| (키) | 고유 이름표 (영문) | `cabbage` |
| `name` | 화면에 보이는 이름 | 양배추 |
| `section` | 장보기 코너 | 채소 |
| `buyUnit` | 사는 단위 | 1통 |
| `staple` | 집에 늘 있는 재료인지 | false |

`section` 값: 정육 · 수산 · 채소 · 두부·계란 · 가공·기타 · 양념·소스 · 곡류

### 7-2. 메뉴 도감 `data/menus.ts`

| 칸 | 뜻 | 예시 |
|---|---|---|
| (키) | 고유 이름표 | `jeyuk` |
| `name` | 메뉴 이름 | 제육볶음 |
| `protein` | 주재료 종류 | 돼지 |
| `method` | 조리법 | 볶음 |
| `special` | 가끔 특식인지 | false |
| `level` | 난이도 | 쉬움 |
| `minutes` | 조리시간(분) | 25 |
| `lunchbox` | 도시락으로 괜찮은지 | true |
| `ingredients` | 장보기용 재료 `[{재료id, 양}]` | `[{cabbage, "1/2통"}]` |
| `sides` | 곁들임 추천 | 양배추 쌈 |
| `keyRatio` | 황금 비율 한 줄 (선택) | 고추장 2 : 간장 1 : 설탕 1 |
| `mainRecipe` | 대표 레시피 id (선택) | `jeyuk-01` |

| `prepOnly` | 밀프랩 전용 (선택) → 저녁 추천에서 빠짐 | true |

- `protein` 값: 돼지 · 닭 · 소 · 생선 · 두부·계란 · 채소 · 남은 재료
- `method` 값: 국물 · 볶음 · 구이 · 조림·찜 · 덮밥·면 · 양식
- `level` 값: 쉬움 · 보통 · 어려움
- **장보기는 언제나 메뉴의 `ingredients`로 만들어요.** 대표 레시피가 정해지면 Claude가 그 레시피에 맞춰 이 칸을 맞춰둬요.

### 7-3. 레시피 `data/recipes/메뉴id.ts`

메뉴 하나에 파일 하나, 안에 영상 최대 5개. 폴더에 파일을 넣기만 하면 앱이 자동으로 모아요 (목록 파일 필요 없음).
재료는 재료 사전에 있으면 `id`, 없으면(우유, 다시다처럼 가끔 쓰는 것) `name`으로 적어요.

| 칸 | 뜻 | 예시 |
|---|---|---|
| `id` | 고유 이름표 | `jeyuk-01` |
| `menuId` | 어느 메뉴인지 | `jeyuk` |
| `video` | 영상 정보 | 아래 표 |

| `tools` | 필요한 도구 | 프라이팬, 볼 |
| `ingredients` | 재료와 양념 `[{재료id, 양, 확인필요?}]` | |
| `steps` | 단계 목록 | 아래 표 |
| `tips` | 팁 (선택) | 고기는 센불에 |

> 다른 영상 4개는 `video`만 채우고 나머지 칸은 비워둬요. 대표로 바꾸면 그때 채워요.

**Vite + React + TypeScript**. 라이브러리는 최소한으로 (화면 이동 · 상태 관리 라이브러리 없음, CSS는 직접 작성).

```
식단앱/
├─ index.html
├─ package.json
├─ vite.config.ts
├─ public/                  홈 화면 아이콘
├─ src/
│  ├─ main.tsx
│  ├─ App.tsx               탭 전환
│  ├─ types.ts              ← 7장 데이터 구조를 코드로 (스키마)
│  ├─ styles/               색 · 글꼴 · 공통 스타일
│  ├─ components/           아이콘, 버튼, 체크박스, 하트
│  ├─ screens/              식단 / 레시피 / 장보기 / 찜
│  ├─ lib/
│  │  ├─ recommend.ts       4장 추천 규칙
│  │  ├─ shopping.ts        장보기 목록 만들기
│  │  └─ storage.ts         내 기록 저장 · 내보내기
│  └─ data/
│     ├─ index.ts         데이터 입구 + 연결 점검
│     ├─ ingredients.ts
│     ├─ menus.ts
│     ├─ prepVideos.ts    밀프랩 "한 번에 여러 개" 영상
│     └─ recipes/
├─ drafts/                  디자인 시안
└─ docs/                    SPEC.md, HANDOFF.md, 조사 자료
```
