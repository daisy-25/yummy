# 한국 레시피·식단·냉장고 파먹기 앱 조사 (2026-10 기준)

> 조사 범위 메모: 사용한 웹 검색 도구가 미국 기준이라 네이버 블로그·커뮤니티·Play 스토어 리뷰 본문은 거의 수집하지 못함(Play 스토어 페이지는 본문이 잘려 읽히지 않음). 근거는 주로 App Store KR 상세 페이지, 실제 레시피 페이지, 기사임. 컬리·SSG·B마트·오늘의집 레시피 기능은 확인 못 함(각 질문의 Gaps 참고).

## 1. 레시피를 어떻게 보여주나 (계량, 인분, 단계 사진, 난이도·시간, 영상)

### Takeaway
한국 레시피 화면의 사실상 표준은 "인분 · 시간 · 난이도" 한 줄 → 재료(숟가락/컵/g 혼용, 일부는 '약간·적당량') → 번호 매긴 단계별 사진+설명 → 후기·댓글 순서다. 확인한 곳 중 **인분 자동 조절은 없었고**, 대신 계량법 안내 팝업(1큰술=15ml 등)으로 초보자를 돕는다.

### Cited Findings
- **만개의레시피 웹 레시피 페이지 구조(위→아래)**: 제목·작성자 → "3인분 30분 이내 아무나"처럼 인분/시간/난이도를 한 줄로 표기(난이도는 '아무나' 같은 쉬운 말) → 공유(URL·카톡) → 스크랩/메모/신고/인쇄 버튼 → [재료] 목록(재료명·양·옆에 **구매** 링크, 단위 g/ml/개/스푼/'약간' 혼용) → 재료 목록 위 **계량법 안내** 링크 → 재료 손질·보관 노하우 카드 → 조리순서(보기 방식 "이미지 크게/텍스트만/이미지 작게" 전환, 단계마다 사진+설명, 팁은 문장 안에) → 완성 사진 → AI 리뷰 요약(긍정 비율)·포토리뷰 → 요리 후기(별점·사진, "유용한 후기순/최근순" 정렬) → 댓글 → 관련 상품 광고(가격·로켓배송 표시) → 관련 레시피 묶음 — [만개의레시피 카레 레시피](https://www.10000recipe.com/recipe/6851792)
- **만개의레시피 계량법 팝업**: 1큰술=15ml, 1작은술=5ml, 1컵=200ml, 1종이컵=180ml, "1꼬집/1줌/1주먹" 손 계량 설명, 재료별 눈대중 무게(양파 중 1개≈170g, 당근 중 1개≈150g, 돼지고기 1토막≈100g), 1국그릇=300ml — [만개의레시피](https://www.10000recipe.com/recipe/6851792)
- 만개의레시피 앱 소개: 레시피 20만여 개, "조리 순서별 이미지와 요리팁으로 요리 초보도" 따라 할 수 있다고 강조. 앱 설명에 인분 조절·계량 환산 기능 언급 없음 — [App Store 만개의레시피](https://apps.apple.com/kr/app/id494190282)
- **우리의식탁(wtable) 레시피 페이지 구조**: 제목+책갈피(스크랩)/공유 → 난이도·소요시간(예: 1시간 20분)·"노트보기(24)" → 작성자(채널) 소개 → 재료를 **요리별 그룹**으로 묶고 그룹마다 분량 표기(예: 육전 4인분, 동그랑땡 16개 분량), 단위는 개/줄/g/컵/큰술/작은술/한줌/약간/적당량 혼용, 재료 이미지 포함 → 번호 매긴 단계 + 단계별 사진, 팁은 괄호로 → 로그인 유도 배너("광고 없이 보려면 로그인", 거절 버튼 문구 "그냥 불편하게 볼래요") → "우리의 노트" 후기(태그: 팁/후기/질문, 좋아요·댓글·사진). 인분 조절·별점·장바구니는 없음 — [우리의식탁 모둠전](https://wtable.co.kr/recipes/hndKibWTxkCSucDn1HFtZmkK)
- **이밥차**(2017 비교 기사): 큰 사진 아래 조리법을 좌우로 넘기는 **카드형**, **화면이 꺼지지 않는 요리 모드**, 타이머, 재료 화면 상단 **밥숟가락 계량 팁**, 레시피 화면에서 '이밥차TV' 영상 바로 재생. 단점: 하단 광고 배너가 화면을 가림 — [앱스토리 2017.04.21](https://news.appstory.co.kr/plan9573)
- **해먹남녀**(2017): 난이도를 냄비 아이콘으로, 소요시간 표시, 일부 단계는 움짤, 영양정보 오각형 그래프. 단점: 요리 모드 없음, 화면당 정보가 적어 스크롤 많음 — [앱스토리](https://news.appstory.co.kr/plan9573)
- **요리보고**(2025.10 출시 개인 개발 앱): 레시피 **단계별 타이머**(2.0.0), 리뷰에서 "백그라운드에서도 타이머 제어" 요청 — [App Store 요리보고](https://apps.apple.com/kr/app/id6753646490)

### Inferences
- 우리 앱은 2인분 고정이므로 인분 조절 UI는 빼도 되고, 레시피 데이터를 처음부터 "2인분 기준"으로 적는 편이 낫다. 대신 만개의레시피식 **계량 안내(1큰술=밥숟가락 약 1.5개 같은 초보용 환산)**를 레시피 화면에 고정해 두면 초보자에게 효과가 크다.
- "인분·시간·난이도" 한 줄 메타 + 단계 번호 + "텍스트만 보기" 전환 + 화면 꺼짐 방지 요리 모드가 가성비 좋은 조합이다(요리 모드는 웹에서 Wake Lock API로 구현 가능).
- 재료와 양념을 나눠 표기하는 곳과 섞는 곳이 있다. 장보기 목록에서 양념(집에 있는 것)과 장 볼 재료를 구분하려면 데이터 단계에서 "기본 양념" 플래그를 따로 두는 것이 좋다.

### Gaps
- 만개의레시피·해먹 앱의 최신 앱 내부 화면(인분 조절 유무)은 직접 확인 못 함. 웹 페이지 기준임.
- 쿠캣·컬리 레시피 페이지 구조는 수집 못 함.

## 2. 주간 식단표 / 자동 장보기 목록 / 비용 추정

### Takeaway
한국 대형 레시피 앱(만개의레시피)은 "장보기 메모" 수준에 그친다. 주간 식단 → 재료 자동 합산 → 마트 연결까지 묶은 곳은 **해먹(테이크유어타임, 2025~)** 같은 신규 앱과 소규모 식단표 앱들이다. **재료 비용 추정 기능은 확인한 어떤 앱에도 없었다.** 우리 앱이 차별화할 수 있는 지점이다.

### Cited Findings
- **해먹(현행 앱)**: 부제 "1주일치 식단 장보기 5분안에 끝내기". 레시피를 고르면 재료가 장바구니에 자동으로 담기고, 레시피에 맞춰 재료량 자동 계산, 일주일 식단 관리, 온라인 마트 연결(리뷰: "컬리에서 바로 주문"이 좋다), 냉장고 재료 AI 추천, 직접 만든 레시피 저장. 업데이트로 식단 계획표, 할인상품 모아보기, 장바구니 식단 기록, 외부 레시피 검색 추가. 개발사 테이크유어타임, 평점 5.0(평가 8개), 리뷰에 "서비스 지역 확대" 요청 — [App Store 해먹](https://apps.apple.com/kr/app/id6747734534)
- **만개의레시피**: 2024.04(6.1.7) "장보기 메모"(장보기 전 필요한 재료 기록)와 "레시피 재료 검색" 추가. 식단표 기능은 설명에 없음 — [App Store 만개의레시피](https://apps.apple.com/kr/app/id494190282)
- **MealPlan(주간 식단표 계획 장보기 리스트 레시피북)**: 월~일 × 아침/점심/저녁을 한 화면에 배치, 보기는 "컴팩트 그리드 / 일별 리스트" 두 가지, **지난주 식단 원탭 복사**, 남은 저녁을 즐겨찾기 요리로 자동 채우기, 저녁 알림(메뉴+준비 시작 시간), 장보기 목록은 모든 끼니에서 재료 추출 → **중복 재료 양 합산** → 마트 통로 순서 정렬 → 매장에서 체크. 완전 오프라인·계정 없음. 비용 계산·인분 조절 언급 없음 — [App Store MealPlan](https://apps.apple.com/us/app/%EC%A3%BC%EA%B0%84-%EC%8B%9D%EB%8B%A8%ED%91%9C-%EA%B3%84%ED%9A%8D-%EC%9E%A5%EB%B3%B4%EA%B8%B0-%EB%A6%AC%EC%8A%A4%ED%8A%B8-%EB%A0%88%EC%8B%9C%ED%94%BC%EB%B6%81-%EC%A0%80%EB%85%81-%EB%A9%94%EB%89%B4/id6772145232?l=ko)
- **식단표 만들기(Google Play, devolim)**: 일주일 식단 → 장보기 목록 한 장, 매대 순서 정렬, PDF/공유, 빈 저녁을 AI가 채움, 냉장고 남은 재료 우선 레시피 제안(스토어 설명 기반, 검색 요약으로만 확인) — [Google Play 식단표 만들기](https://play.google.com/store/apps/details?id=com.devolim.weeklymenu&hl=ko)
- 그 밖에 FoodCraft(웹, 확정 식단 → 겹치는 재료 합산·코너별 분류), PantryMix(레시피에서 부족한 재료만 목록에 추가) — [FoodCraft 가이드](https://foodcraft.app/ko/guide/jugan-sigdan-gyehoek), [PantryMix](https://pantrymix.com/ko/use-cases/recipe-to-shopping-list/)
- 해먹남녀 2.0(과거)은 "식사 인원, 주간 요리 횟수, 시간대" 입력으로 맞춤 요리를 추천했음(식단표는 아님) — [플래텀](https://platum.kr/archives/63703) (본문 403, 검색 요약 기반)

### Inferences
- 우리 앱에 바로 가져올 패턴: ① 7일 × 저녁 1칸 그리드(2인 가구는 저녁만으로 충분), ② "지난주 복사" 버튼, ③ 장보기 = 식단 재료 자동 합산 + 체크박스 + 코너(정육/채소/양념) 그룹, ④ 집에 있는 양념은 기본으로 빼 두기.
- 비용은 어디에도 없으므로 재료마다 "대략 단가(원)"를 수동 입력해 두고 주간 합계를 보여주는 단순한 방식이 현실적이다. 가격 API 연동은 과하다.

### Gaps
- 이마트·SSG, 컬리, B마트의 "레시피 재료 한번에 담기"는 검색으로 확인 못 함.
- 아이 식단·어린이집 주간 식단표 서비스는 조사하지 못함.

## 3. 냉장고 재료로 메뉴 추천 (입력 방식, 매칭 로직)

### Takeaway
입력은 대부분 **재료 칩 직접 추가/삭제**(일부는 사진 인식)이고, 매칭은 "보유 재료 포함 여부"가 기본이다. 좋은 앱은 여기에 **제외 재료**, **꼭 들어갈 재료**, **부족한 재료 → 장보기**, **재료 수(간단도) 필터**를 얹는다.

### Cited Findings
- **만개의레시피 '냉장고 파먹기'**: 보유 재료로 만들 수 있는 레시피 추천 + **제외 재료 입력** 가능. 리뷰: 집에 있는 재료 위주로 고를 수 있어 아이 방학 식단에 도움(2022), 재료명 검색 시 레시피가 잘 나오고 여러 사람의 조리법을 비교할 수 있다(2019) — [App Store 만개의레시피](https://apps.apple.com/kr/app/id494190282)
- **냉쿡(유튜브 레시피로 냉장고 털기)**: 재료 입력 → AI가 유튜브 요리 영상 추천. 레시피별 재료를 **필수/있는 것/없는 것/선택/대체** 다섯 태그로 분류해 준비 상태를 보여주고, 부족한 재료로 장보기 계획을 돕는다. 입력 재료와 연관된 재료 자동 제안, "꼭 쓸 재료" 지정 시 실제로 그 재료가 들어간 영상만 필터, 재료 수 기준 "매우 간단/간단/보통/많음" 버튼, 인기 요리 채널 선택, 영상 저장 — [App Store 냉쿡(검색 스니펫)](https://apps.apple.com/kr/app/id6745560834) (KR 상세 페이지는 직접 열었을 때 404, 다른 국가 스토어 페이지와 검색 요약으로 확인. 내려갔을 수 있음)
- **요리보고**: 재료 추가/삭제 → 보유 재료와 맞는 레시피 자동 추천, 유통기한 D-3/D-1/D-Day 로컬 알림, 2.1.0부터 냉장고 재료를 실사 이미지로 표시. 리뷰: "메뉴 고민 시간이 크게 줄었다" — [App Store 요리보고](https://apps.apple.com/kr/app/id6753646490)
- **냉장고 털기(Google Play)**: "AI 식재료 분석" 사진으로 재료 인식(검색 결과 제목·요약 기준, 상세 미확인) — [Google Play 냉장고 털기](https://play.google.com/store/apps/details?id=com.gonigon.refrigeratorcheck&hl=ko)
- **냉장고 파먹기: 레시피, 냉장고 관리, 집밥, 냉파(Google Play)** 존재 확인(상세 미확인) — [Google Play](https://play.google.com/store/apps/details?id=com.lazyheroes.erfe&hl=en_US)
- 과거 '밥타임' 앱이 냉장고 속 재료로 바로 만들 수 있는 메뉴를 추천했다(2017 기사) — [영남일보 2017](https://www.yeongnam.com/web/view.php?key=20170209.010190757010001)

### Inferences
- 우리처럼 고정 레시피가 수십 개인 앱이면 AI 없이 "보유 재료 체크 → 레시피별 '없는 재료 n개' 표시 → 적은 순 정렬"만으로 충분하다. 냉쿡의 "있음/없음/선택(대체 가능)" 구분이 가장 쓸 만한 아이디어다.
- 양념류(간장·고춧가루 등)는 매칭에서 빼거나 '항상 있음'으로 처리해야 결과가 의미 있어진다.

### Gaps
- 실제 매칭 알고리즘(가중치, 주재료 vs 부재료)은 어느 앱도 공개하지 않음.
- 마이냉장고 등 냉장고 관리 앱은 확인 못 함.

## 4. "오늘 뭐 먹지" 메뉴 추천 / 룰렛

### Takeaway
"오늘 뭐 먹지"는 대형 앱의 메뉴 하나(만개의레시피)이거나, 독립 룰렛 앱·웹으로 많이 나와 있다. 패턴은 **카테고리 선택 → 무작위 뽑기**, **후보 직접 추가**, **제외 메뉴**, **이상형 월드컵/카드 스와이프**다.

### Cited Findings
- 만개의레시피에 "오늘 뭐 먹지: 메뉴 고민 해결" 메뉴가 있음 — [App Store 만개의레시피](https://apps.apple.com/kr/app/id494190282)

## 5. 유튜브 요리 채널 연동

### Takeaway
대형 레시피 앱은 자체 영상(이밥차TV, 쿠캣 영상)이 중심이고, 백종원 등 외부 유튜브 채널과 연동하는 공식 앱은 찾지 못했다. 2025~2026년에는 **유튜브 영상에서 AI로 재료·단계를 뽑아 텍스트 레시피로 만드는** 개인 개발 앱(쿠버, 해먹으리, 냉쿡)이 새로 나오는 추세다.

### Cited Findings
- 백종원 공식 레시피 앱은 확인되지 않음. 유튜브 채널 '백종원의 요리비책'은 2019.06.11 개설(첫날 제육볶음 100인분 등 8개), 2022년 11월경 채널명 '백종원'으로 변경. 개설 이유는 인터넷에 떠도는 잘못된 백종원 레시피를 바로잡기 위해서였음 — [부산일보](https://www.busan.com/view/busan/view.php?code=2019061115394913368), [나무위키](https://namu.wiki/w/%EB%B0%B1%EC%A2%85%EC%9B%90/%EC%9C%A0%ED%8A%9C%EB%B8%8C%20%EC%B1%84%EB%84%90)
- 쿠버(유튜브 요리 레시피 모음): 유튜브 요리 영상에서 AI가 재료와 조리 과정을 자동 추출해 정리(검색 요약 기준, KR 상세 페이지는 404) — [App Store 쿠버](https://apps.apple.com/kr/app/id6761064877)
- 해먹으리: "AI가 SNS 요리 영상을 레시피로!" — [App Store 해먹으리](https://apps.apple.com/us/app/%ED%95%B4%EB%A8%B9%EC%9C%BC%EB%A6%AC-ai%EA%B0%80-sns-%EC%9A%94%EB%A6%AC-%EC%98%81%EC%83%81%EC%9D%84-%EB%A0%88%EC%8B%9C%ED%94%BC%EB%A1%9C/id6748438087?l=ko&platform=watch)
- 냉쿡: 재료 기반으로 유튜브 영상을 추천하고 인기 요리 채널을 골라 보는 기능 — [App Store 냉쿡](https://apps.apple.com/kr/app/id6745560834)
- 이밥차: 레시피 화면에서 자체 '이밥차TV' 영상 바로 재생 — [앱스토리](https://news.appstory.co.kr/plan9573)
- 쿠캣: '오늘 뭐 먹지?' 커뮤니티·레시피 영상 채널 등 약 70개 콘텐츠 → 구독자 데이터로 PB 상품 기획하는 콘텐츠 커머스 구조. 상품 이미지도 움직이는 영상으로 보여줌(2024.02 글) — [PM다이닝](https://maily.so/pmdining/posts/2nznp2lkrp5)
- 해먹(현행)은 "외부 레시피 검색"을 업데이트로 추가 — [App Store 해먹](https://apps.apple.com/kr/app/id6747734534)

### Inferences
- 개인 앱에서는 레시피마다 유튜브 링크 1개와 **시작 시간(`?t=초`)**을 저장하고, 텍스트 레시피를 함께 보여주는 방식이 현실적이다. 영상은 임베드(iframe)보다 "영상 보기" 버튼으로 앱 열기가 모바일에서 더 가볍다.
- 백종원 레시피는 맹신하지 말고 참고하라는 본인 발언처럼 영상과 텍스트가 다를 수 있으므로, 텍스트 레시피에 "출처 영상" 표기를 두면 좋다.

### Gaps
- 1분요리 뚝딱이형·정호영 채널과 정식 제휴한 앱은 찾지 못함.
- 영상 타임스탬프를 단계에 연결하는 한국 앱은 확인 못 함.

## 6. 커뮤니티(후기·사진 인증·별점)와 스크랩(찜)

## 8. 한국 특유의 패턴: 밀키트·장바구니 연동, 1~2인 가구

### Takeaway
"레시피 → 마트 장바구니" 연동은 실제로 있다(해먹 → 컬리 주문, 만개의레시피 재료 옆 '구매' 링크와 로켓배송 광고). 레시피 앱들이 커머스로 수익을 내는 흐름이 뚜렷하다. 1~2인 가구 전용 콘텐츠는 이번 조사에서 확인하지 못했다.

### Cited Findings
- 해먹: 레시피 선택 → 재료 장바구니 자동 담기 → 온라인 마트 연결, 리뷰상 컬리에서 바로 주문 가능, 할인상품 모아보기 — [App Store 해먹](https://apps.apple.com/kr/app/id6747734534)
- 만개의레시피: 재료마다 '구매' 링크, 하단 관련 상품 광고(가격·로켓배송), 만개 스토어 — [레시피 페이지](https://www.10000recipe.com/recipe/6851792), [App Store](https://apps.apple.com/kr/app/id494190282)
- 쿠캣: 콘텐츠로 모은 데이터로 PB 간편식 기획, '쿠캣신공' 선착순 할인(22회차 완판, 82% 당일 완판) — [PM다이닝](https://maily.so/pmdining/posts/2nznp2lkrp5)
- 우리의식탁: 셀러샵(2025), 결제 시스템 개편(2026.09) — [검색 요약](https://apps.apple.com/kr/app/%EC%9A%B0%EB%A6%AC%EC%9D%98%EC%8B%9D%ED%83%81-%EC%9A%94%EB%A6%AC%EB%A5%BC-%EC%8A%A4%ED%83%80%EC%9D%BC%ED%95%98%EB%8B%A4/id1090371750)
- 해먹남녀 2.0은 "식사 인원"을 입력받아 추천했다(인원 맞춤의 초기 사례) — [플래텀](https://platum.kr/archives/63703)

### Inferences
- 개인 앱에서는 장보기 목록의 재료마다 "쿠팡/컬리 검색" 딥링크(검색어 URL)를 붙이는 정도면 충분하다. 장바구니 API 연동은 불필요하다.
- 2인 가구는 재료가 남는 것이 가장 큰 문제다. 같은 주에 재료를 이어 쓰는 메뉴 조합(예: 대파·양파·돼지고기를 제육볶음과 김치찌개에 나눠 쓰기)을 장보기 화면에서 "이 재료는 2개 메뉴에서 사용"처럼 보여주면, 확인한 어떤 앱에도 없는 기능이 된다.

### Gaps
- 컬리 매거진/레시피, SSG·이마트 레시피, 배민 B마트 레시피, 오늘의집 레시피 기능은 검색 도구 한계로 확인 못 함.
- 도시락 계획 콘텐츠, 아이 식단표 서비스는 조사하지 못함.
